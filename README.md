# Landing Page Penjualan Produk Digital

Frontend statis (HTML/CSS/JS murni) untuk GitHub Pages + backend Google Apps Script (REST API JSON).

- `index.html` — halaman penjualan publik
- `admin.html` — panel admin (login)
- `js/config.js` — **satu-satunya berkas yang perlu Anda edit**: isi `API_URL`
- `css/`, `js/`, `img/` — gaya, skrip, gambar contoh

Tanpa `API_URL` situs berjalan di **mode demo** (data contoh di browser; login `admin@demo.com` / `demo1234`).
Langkah lengkap: lihat `PANDUAN-INSTALASI.md` (dikirim terpisah, bukan bagian ZIP ini).
